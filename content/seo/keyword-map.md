## GAPS (unbesetzt, mit Intent)

1. **"MCP-fähig machen" / "Software MCP-fähig machen" / "agentenfähig machen"** — TRANSAKTIONAL/STRATEGISCH, höchste Priorität.
   Belegt nur von Produkt-Anbietern (Kobel App-Proxy, Tutorials für SAP/Logic Apps)
   und dem EN-Pendant (dev.to, Cyclr: "Make your SaaS AI-agent ready"). Kein
   deutschsprachiger Strategie-Leitfaden von einem Dienstleister. **"agentenfähig"
   als deutsches Wort hat null Suchergebnisse** — unbesetztes Markenwort, das wir
   bereits überall verwenden.
2. **"MCP-Agentur" / "MCP-Agentur Deutschland" / "MCP-Beratung" / "MCP Consulting"** — TRANSAKTIONAL.
   Konkurrenz: [mcp-agency.com](https://www.mcp-agency.com) (EN, international),
   [Workflow-Agentur](https://www.workflow-agentur.com) (Hamburg, "DSGVO-konforme
   MCP-Server"). Kein Vergleichs-/Auswahl-Content auf Deutsch.
3. **"MCP vs Agent Skills"** — INFORMATISCH, frisch. till-freitag.com und
   bürofuerki.ch haben deutsche Stücke; EN breit (atlan, cosmicjs, logto).
   Themen-Halbwertszeit hoch, jetzt rein.
4. **"KI-Agenten anbinden" / "KI-Agenten integrieren"** — breit besetzt von
   generischen KI-Beratungen (ki-beratung-deutschland.de, Prismetric, amber).
   Differenzierung nur über unsere Report-Daten. Mittlere Priorität.
5. **"MCP-Audit" / "Agent-Readiness-Audit"** — unser Money-Keyword. Money-Page
   /mcp-audit existiert; unterstützender Artikel fehlt.
6. **"MCP Server Hosting" / "MCP Server betreiben"** — Retainer-adjacent. Queue.

## Konkurrenz-Scan (wer verkauft was)

  Inhalte, kein Report/Daten-Fundament.
- **workflow-agentur.com** (Hamburg) — DE, MCP-Server "DSGVO-konform", direkt
  vergleichbares Angebot. Beobachten.

  der Proxy-Weg als Produkt. Natürlicher Kontrast für unseren drei-Wege-Artikel.

- **Generische KI-Beratungen** (ki-beratung-deutschland.de u. a.) — verkaufen
  KI-Agenten-Projekte, haben kein MCP-/Report-Fundament.
- **Big-Tech-Content** (IBM, DataCamp, Red Hat, Cloudflare, Bright Data) —
  owns Explainer/Tutorial-Cluster; Kopf-Keywords nicht frontal angreifen.
